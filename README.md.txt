# CodeOrbit To-Do List CLI App

## Description
This is a simple Command Line To-Do List application developed using Python.

## Features
- Add new tasks
- View all tasks
- Remove completed tasks
- User-friendly menu
- Handles invalid input

## Technologies Used
- Python 3

## How to Run

1. Open the project folder.
2. Open Terminal.
3. Run:
   python todo.py

## Sample Output

===== TO-DO LIST =====

1. Add Task
2. View Tasks
3. Remove Task
4. Exit
